Professional Prompt — Intelligent, Fully Configurable Admin Dashboard for Unns

You are not simply building an admin panel.

You are designing and implementing the central command system for Unns, an advanced emotional operating system.
This dashboard must function as a live operational brain, allowing the business, product, operations, AI, marketing, support, and technology teams to control, tune, monitor, and evolve the product without requiring code changes, redeployment, or direct developer intervention whenever the change is business-configurable.

Your responsibility is to architect this system as a configuration-driven, permission-aware, highly secure, scalable, and operationally intelligent platform that can support a complex AI-powered emotional wellness product at scale.

2) Core Product Philosophy

The Admin Dashboard must follow these principles:

A. Configuration over Code

Any function, threshold, rule, parameter, workflow, or experience that can reasonably be configurable must not be hardcoded.

B. Business Agility

Product and operations teams must be able to adjust system behavior immediately without waiting for engineering whenever code changes are not technically required.

C. Safety by Design

Every configuration capability must be protected by permissions, logs, validation rules, and rollback mechanisms.

D. Observability by Default

The dashboard must not only control the system, but also explain what is happening, what changed, why it changed, and what the operational impact is.

E. Scalable Governance

As the product grows, the dashboard must be able to support multiple roles, workflows, teams, environments, AI providers, user segments, and regional rules.
